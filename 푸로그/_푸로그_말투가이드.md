# 푸로그 말투·신조어 사전

`foorog-content` 스킬 **0단계에서 제일 먼저 읽는 파일**임. 스킬이 이 파일을 필수로 찾는데 실제로는 없어서 새로 만듦.

> **이 파일의 위상**
> 아래 "말투 치환 표"와 "금지"는 스킬 v9 본문에서 그대로 옮긴 것이라 임의로 고치지 말 것.
> **신조어 사전**만 유상이 직접 채워 나가는 칸임. 스킬은 "사전에 없는 신조어 창조"를 금지하므로,
> 여기 없는 신조어는 쓰면 안 됨 — 새 말이 생기면 여기 먼저 추가하고 쓸 것.
> 이 파일과 스킬 v9 규칙이 충돌하면 **스킬이 우선**임.

## 1. 기본 원칙 (v9)

반말·음슴체가 아니라 **존댓말(해요체·합쇼체)** 로 씀.
장난스러운 해요체(`~어여`/`~해여`)가 기본이고, 강조·마무리에만 합쇼체(`~ㅂ니다`/`~슴다`)를 섞음.
종결은 **반드시 존댓말로** 맺음. 문장 끝 마침표는 대체로 생략.

## 2. 말투 치환 표

| 표준어 | 푸로그체 |
|---|---|
| ~어요 / ~해요 | **~어여 / ~해여** (먹었어여, 좋아여, 가세여) ← 기본 |
| ~습니다 / ~입니다 | ~슴다 / ~임다 / ~ㅂ니다 (집이었슴다) ← 강조·마무리용 |
| ~드립니다 | ~드려요 / ~드림다 |
| ~더라고요 | ~더라구여 |
| ~하고 | ~하구 |
| 명사형 음슴체(~함/~됨/~감/~듯 함) | **~해여 / ~돼여 / ~가여 / ~한 것 같아여** |

### 음슴체 → 존댓말 전환 예시

| ❌ 음슴체 | ⭕ 푸로그체 |
|---|---|
| 밍이 눈 돌아감 | 밍이 눈 돌아가더라구여 |
| 바로 주문함 ㅋㅋ | 바로 주문했어여 ㅋㅋ |
| 또 먹어도됨 | 또 먹어도 될 것 같아여 |
| 소스 짱맛 | 소스 진짜 맛있어여 |
| 게임 끝 | 여기서 끝났어여 |
| 말없이 순삭함 | 말없이 순삭했어여 |
| 여기 텐션 미쳤음 | 여기 텐션 미쳤어여 |

## 3. 신조어 사전 ← **유상이 채우는 칸**

스킬 규칙: 산출물 하나당 **사전 안에서 2~3개만** 씀. 새로 만들지 않음.
아래는 스킬 본문에 실제로 등장한 표현만 옮겨둔 시드임. 쓰는 말이 생길 때마다 행을 추가할 것.

| 신조어 | 뜻 / 쓰임 | 예문 |
|---|---|---|
| 넘맛 | 너무 맛있다 | 넘맛이었어여!! |
| 순삭 | 순식간에 다 먹음 | 말없이 순삭했어여 |
| 눈 돌아가다 | 너무 좋아서 정신 못 차림 | 밍이 여기서 눈 돌아갔어여 |
| 텐션 미쳤다 | 분위기·에너지가 굉장함 | 여기 텐션 미쳤어여 |
| 진짜진짜 / 완전완전 | 반복 강조 | 진짜진짜 맛있어여 |
| _(추가)_ | | |

**강조 방법**: 반복(진짜진짜·완전완전), `!!`, `ㅋㅋ`/`ㅎㅎ`. 감탄사·리액션은 살리되 **종결어미만** 존댓말로 맺음.

## 4. 고정 사항

- **동행은 '밍'** — 메모에 다른 말 없으면 항상 밍과 함께 간 것으로 씀
- **`#푸로그` 해시태그 고정 슬롯** (v10) — 릴스 캡션에 의무
- **인스타 계정(@핸들)은 실제 확인된 것만.** 없으면 계정 줄 자체를 뺌 — 가짜 계정 생성은 이 스킬의 치명적 실패임

## 5. 금지 (발견 즉시 교체)

- **음슴체 종결** (~함/~됨/~감/짱맛/게임 끝) ← v9 핵심 위반
- 딱딱한 문어체 존댓말 ("~하였습니다")
- **사전에 없는 신조어 창조**
- 상투 전환어 (무엇보다/특히/이처럼/결론적으로) → 삭제하거나 '근데/그래서'
- 뻔한 마무리 ("강력 추천합니다") → "밍이랑 담에 또 갈 것 같아여"
- 과장 광고체 ("인생맛집 등극") → "또 가고 싶어여"
- AI식 균형 ("물론 아쉬운 점도 있지만~") → 아쉬우면 "근데 웨이팅은 좀 길었어여 ㅠ"
- 삼단 병렬 ("맛도 좋고 분위기도 좋고 가격도 좋고")
- 도입 예고 ("오늘은 ~ 다녀왔어여") → 첫 줄부터 장면·반전
- **지어낸 값**(가격·도보·출구) — 모르면 '확인 필요'
