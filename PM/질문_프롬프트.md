# 50억 플랜 질문 프롬프트

복사해서 그대로 붙여넣으면 됨. `[ ]` 안만 바꿀 것.

## 1. 큰 질문 (전략을 다시 짤 때 · 분기 1회)

```
너는 내 자산증식 PM이야. 먼저 이 레포의 PM/pm_data.json과 자산증식 현황판
(https://claude.ai/artifact/JAGL59ZiDat27rcUAaUAz3)을 읽고 시작해.

목표: 만 40세(2034년 말)에 여의도 삼부아파트 실거주 + 금융자산 10억 = 50억.
지금 상황: [순자산 ○억 / 순금융자산 ○억 / 월 부업 현금수익 ○만 / 이번 분기 바뀐 것]

이번에 알고 싶은 것: [예: 2034에 50억이 안 되는 갭을 메우는 방법 3가지]

조건:
- 주 10시간 안에서 할 수 있는 것만. 본업 소속·사내 자료는 절대 쓰지 않음
- 계산기 숫자로 근거를 보여주고, 안 되는 건 안 된다고 말해줘
- 답은 "지금 할 1개 / 이번 달 3개 / 하지 말 것 1개"로 끝내줘
- 결정이 바뀌면 pm_data.json과 현황판까지 고쳐줘
```

## 2. 월간 PM (매월 1일)

```
월간 PM 해줘. 자산 시트, 퍼플앤트 현황판, 푸로그 작전판 직접 확인해서
계기판·체크·이번 달 할 일 갱신하고, 2034 계획선 대비 위인지 아래인지 판정해줘.
이번 달에 특별히 있었던 일: [없으면 생략]
```

## 3. 주간 PM (매주 월요일)

```
주간 PM 해줘. 지난주 체크 읽고 회고 3줄, 이번 주 할 일 7개 이하로.
이번 주 쓸 수 있는 시간: [○시간] · 컨디션: [좋음/보통/지침]
```

컨디션을 '지침'으로 쓰면 최소선 3개만 남기라고 요청하는 것과 같음.

## 4. 결정이 필요할 때 (돈이 크게 움직이는 일)

```
[예: 지금 집 팔고 여의도 구축으로 갈아탈지 / ISA에 얼마 넣을지 / 새 부업 시작할지]
이걸 2034 삼부 입성 목표 기준으로 판단해줘.
- 하면 2034 순자산이 몇 억 바뀌는지 계산기로
- 최악의 경우 얼마 잃는지
- 세금·대출 규제에서 확인해야 할 것
- 그래서 할지 말지 한 줄 결론
```

## 5. 새 돈벌이 아이디어가 떠올랐을 때

```
이 아이디어 평가해줘: [아이디어]
현황판의 '돈 버는 방법' 표와 같은 기준으로 — 규모, 열리는 조건, 주당 시간,
기존 축(퍼플앤트·푸로그·사이드)과 겹치는지. 지금/나중/안 함 중 하나로 판정하고
'지금'이면 이번 주 할 일 하나로 쪼개줘.
```

## 잘 묻는 요령

- **숫자를 같이 줄 것.** "요즘 잘 안 돼"보다 "블로그 일방문 124, 대기 글 21편"이 답을 바꿈
- **한 번에 하나만 결정할 것.** 질문이 여러 개면 번호를 붙이면 됨
- **지칠 땐 지쳤다고 쓸 것.** 계획을 줄이는 것도 PM의 일임
